# NetWatch

どのアプリケーションが、どこと、どれくらい通信しているかをリアルタイムに表示する Windows 用モニターです（プロトタイプ v0.4.1）。

## できること

- **接続一覧**：TCP / UDP（IPv4・IPv6）の接続を、プロセス名・PID・ローカル/リモートのアドレスとポート・状態つきで 1 秒ごとに表示
- **通信量**：接続ごと・プロセスごとの送受信速度（↑↓）と累計バイト数 ※管理者権限が必要
- **ドメイン名**：DNS クエリを監視して、IP を `example.com` のようなホスト名で表示 ※管理者権限が必要。名前が取れない IP は「逆引き DNS」をオンにすると PTR で補完します
- **短命な接続の検出**：1 秒の更新の合間に開いて閉じた接続も、ETW の送受信イベントから拾って「(短命)」として表示
- **変化の可視化**：新しい接続は緑色でハイライトし、閉じた接続は 5 秒間薄く表示してから消す
- **絞り込み**：左のプロセス一覧をクリックするとそのプロセスだけを表示。検索ボックスではプロセス名・IP・ドメイン・ポートで絞り込み
- **通信先の記録**：「● 記録開始」〜「■ 停止して保存」の間に通信した宛先を集計し、CSV（Excel 対応）か JSON で保存
- **国別マップ**：宛先 IP から国を判定し、どの国と多く通信しているかを世界地図とランキングで表示（メニュー「表示」→「国別の通信先マップ」／ Ctrl+M）
- **右クリックメニュー**：IP / ホスト名をコピー、ipinfo.io で IP を調べる、実行ファイルの場所を開く

## 通信先の記録

1. 必要なら「🎯 記録対象」で記録するプロセスを選ぶ（下記）
2. ツールバーの「● 記録開始」を押す（ボタンが赤くなり、経過時間と宛先の件数が表示される）
3. 調べたい操作をする
4. 「■ 停止して保存」を押し、保存先と形式（CSV / JSON）を選ぶ

- 保存ダイアログをキャンセルしても、次に記録を始めるまでは「💾 保存」からもう一度保存できます
- 記録中にウィンドウを閉じると、保存するかどうかを確認します
- 画面の表示フィルタ（UDP・ループバック・検索など）や一時停止とは関係なく、ループバック以外のすべての宛先を記録します（記録対象を選んだ場合はそのプロセスだけ）
- 同じ実行ファイル（例：chrome.exe の複数プロセス）から同じ宛先への通信は 1 行にまとめ、PID は空白区切りで並べます
- 通信量とホスト名、UDP の宛先は管理者権限で実行しているときだけ記録されます（通常権限では TCP の接続先のみ）

### 記録対象のプロセスを選ぶ

- 「🎯 記録対象」を押し、「選択したプロセスだけ記録」にしてチェックを入れる（複数選択可）
- 候補は実行中のプロセスで、通信中のものには「● 通信中」と表示。検索ボックスで絞り込めます
- 左のプロセス一覧や接続一覧を右クリック →「記録対象に追加」でも追加できます
- プロセス名（例：`chrome.exe`）で判定するので、同じアプリの別プロセスや記録中に再起動したプロセスも対象になります
- 選択内容は `%AppData%\NetWatch\settings.json` に保存され、次回起動時も引き継がれます
- 記録中は対象を変更できません
- JSON で保存した場合は `targets` に対象プロセスが入ります（すべての場合は `null`）

### CSV の列

| 列 | 内容 |
|---|---|
| プロセス名 / 実行ファイル / PID | 通信したアプリ |
| プロトコル / リモートIP / リモートポート | 宛先 |
| ホスト名 | DNS の監視（または逆引き）で分かった名前 |
| 初回 / 最終 | その宛先との通信を最初と最後に確認した時刻 |
| 接続数 | 確認できたローカル側エンドポイントの数 |
| 送信バイト / 受信バイト | 記録期間中の合計 |

## 国別の通信先マップ

メニュー「表示」→「🌍 国別の通信先マップ」、ツールバーの「🌍 国別マップ」、または Ctrl+M で開きます。

- 地図の色が濃い（オレンジに近い）ほど、その国との通信が多いことを示します（対数スケール）
- 色の基準を「通信量」「接続数」「宛先 IP 数」から選べます（通信量は管理者権限が必要）
- 右側はランキング。国ごとの割合・送受信量・接続数・IP 数・通信したプロセスを表示します
- 地図か一覧で国をクリックすると、下にその国の宛先 IP（ホスト名・プロセス・通信量）が出ます
- 集計はアプリ起動時（または「集計をリセット」を押した時点）からの累計です。画面の表示フィルタとは関係なく、ループバック以外のすべての通信を数えます
- プライベート IP（LAN・CGNAT・リンクローカルなど）は既定で除外。「ローカルネットワークも含める」で一覧に出せます

### 国の判定について

- [DB-IP](https://db-ip.com) の「IP to Country Lite」データベース（CC BY 4.0）をアプリに同梱しているので、オフラインでも動きます
- 毎月更新されるので、「GeoIP データベースを更新」で最新版を `%AppData%\NetWatch` にダウンロードできます
- 判定は「その IP アドレスが登録されている国」です。Cloudflare・Google・Akamai などの CDN や Anycast の IP は、実際に通信しているサーバーの場所とは違う国になることがあります

## 仕組み

| 情報 | 取得方法 | 権限 |
|---|---|---|
| 接続一覧＋PID | `GetExtendedTcpTable` / `GetExtendedUdpTable`（iphlpapi.dll） | 不要 |
| 通信量 | ETW カーネルプロバイダ `NetworkTCPIP`（TcpIp/UdpIp の Send/Recv イベント） | 管理者 |
| ドメイン名 | ETW `Microsoft-Windows-DNS-Client`（イベント 3008） | 管理者 |
| 国 | DB-IP Country Lite（MaxMind DB 形式）を MaxMind.Db で検索 | 不要 |
| プロセスのパス | `QueryFullProcessImageName` | 不要（一部のシステムプロセスは取得不可） |

パケットの中身はキャプチャしていません（ドライバ不要）。

## ダウンロード

[Releases](../../releases) から `NetWatch-vX.Y.Z-win-x64.zip` をダウンロードし、展開して `NetWatch.exe` を実行してください。
exe 1 つに .NET ランタイムごとまとめてあるので、インストールは不要です（初回起動時のみ `%TEMP%\.net\NetWatch\` への展開で数秒かかります）。

## ビルドと実行

必要なもの：Windows 10/11、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
dotnet run                 # そのまま起動
.\publish.ps1              # 単一ファイル版（NetWatch.exe）を publish\ に出力
.\publish\NetWatch.exe --selftest   # 動作確認（結果は selftest.log、管理者で実行すると ETW も確認）
```

起動後、上部の「🛡 管理者として再起動」を押すと通信量とドメイン名が表示されるようになります。

## 既知の制限

- ETW のセッションは同時に作れる数に上限があります。他の監視ツールと併用して開始に失敗した場合は、ステータスバーにエラーが出ます
- アプリが異常終了した場合、ETW セッション「NetWatch-Kernel」「NetWatch-Dns」が残ることがあります（次回起動時に作り直されます。手動で消す場合は `logman stop NetWatch-Kernel -ets`）
- svchost.exe はサービス名まで区別していません
- HTTPS の通信内容は見えません（見えるのは宛先と量のみ）
