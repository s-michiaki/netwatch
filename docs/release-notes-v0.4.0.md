プロセスごとの通信先をリアルタイムに表示する Windows モニターの最初のリリースです。

## ダウンロード
`NetWatch-v0.4.0-win-x64.zip` を展開して `NetWatch.exe` を実行してください（Windows 10/11 x64、.NET のインストール不要）。
通信量とドメイン名の表示には、アプリ上部の「🛡 管理者として再起動」で管理者権限が必要です。

## 主な機能
- **接続一覧**：TCP / UDP（IPv4・IPv6）の接続をプロセス名・PID・宛先・状態つきで 1 秒ごとに更新
- **通信量・ドメイン名**：ETW で接続・プロセスごとの送受信速度と累計、DNS 名を取得（管理者権限）
- **短命な接続の検出**、新規接続のハイライト、プロセス別サマリー、検索・フィルタ
- **通信先の記録**：開始〜停止の間に通信した宛先を集計し、CSV（Excel 対応）/ JSON で保存
- **記録対象の選択**：プロセス名で複数選択（設定は次回起動時も保持）
- **国別の通信先マップ**：宛先 IP から国を判定し、世界地図とランキングで表示（Ctrl+M）

## 注意
- 未署名の実行ファイルなので、初回起動時に SmartScreen の警告が出ることがあります（「詳細情報」→「実行」）
- 国の判定は IP の登録国です。CDN / Anycast の IP は実際のサーバー位置と異なることがあります
